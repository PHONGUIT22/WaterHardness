# WaterHardness.uk - UK Water Hardness & Appliance Calibration Tool

An open-source utility and programmatic dataset for checking hyper-local drinking water hardness metrics (PPM, Clark Degrees, French Degrees) across UK postcodes.

🔗 **Live Tool & Database:** [https://waterhardness.uk](https://waterhardness.uk)

## Features
- **Hyper-local Lookup:** Query water hardness levels by UK postal districts (e.g., SW1, BS1, M1).
- **Appliance Guides:** Recommended settings for dishwashers, combi boilers, and coffee machines.
- **Open Data:** Compiled from UK Water Supplier Zones (WSZ) and DWI drinking water quality compliance reports.
